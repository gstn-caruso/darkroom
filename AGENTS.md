# Project constraints

- Darkroom is an independent native GTK photo editor written in Vala. Stay within the GNOME/GTK ecosystem.
- Use native GTK 4 widgets and native libadwaita GNOME components throughout the UI. Do not use Electron, WebViews, or web-based UI. Native GTK CSS styling and image textures are allowed.
- Keep source, comments, UI text, documentation, and contribution discussions in English.
- The application is free software under GPL-3.0-or-later; contributions must be compatible with that license. AppStream metadata is CC0-1.0.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for TDD, build, test, packaging, and contribution commands. Preserve the GTK 4.10 and libadwaita 1.4 minimums.
